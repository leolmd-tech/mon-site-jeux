MiniCraft 3D

Jeu Voxel 3D dans le navigateur

🖥️ Ordinateur

  • Déplacement : ZQSD / WASD / Flèches
  • Regarder : Souris (Pointer Lock)
  • Sauter : Espace
  • Casser : Clic gauche
  • Poser : Clic droit
  • Sélection : Touches 1 à 5 ou clic hotbar

📱 Mobile

  • Joystick gauche : Déplacements
  • Glisser à droite : Orienter la vue
  • Boutons bas : Casser, Poser, Sauter
  • Hotbar : Tap pour sélectionner le bloc
